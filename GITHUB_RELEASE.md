## 💻 Using the Executable Files

### LaptoPilot.exe (Portable Version)
This is a portable version of LaptoPilot that can be run directly without installation:
1. Download `LaptoPilot.exe` from the releases page
2. Double-click the file to run it
3. If Windows SmartScreen appears, click "More info" then "Run anyway"
4. The application will start immediately without any installation process
5. All data is stored locally on your machine

### LaptoPilot Setup.exe (Installer Version)
This is a traditional installer that will set up LaptoPilot on your system:
1. Download `LaptoPilot Setup.exe` from the releases page
2. Double-click the file to run it
3. If Windows SmartScreen appears, click "More info" then "Run anyway"
4. Follow the installation wizard to complete the setup
5. The application will be installed to your Program Files directory
6. A shortcut will be created on your desktop and in the Start menu
